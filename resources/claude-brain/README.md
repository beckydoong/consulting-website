# Your Claude Brain — Starter Files

A "Claude brain" is just a Claude Project loaded with a few Markdown files about
you and your work. Once they're in the Project, Claude reads them as background on
every chat, so you never start from a blank prompt again.

## How to set it up (15–30 minutes)

1. Go to **claude.ai → Projects → Create Project**. Name it "My Second Brain."
2. Add these files to the Project's knowledge (use **Add content** or the paperclip):
   - `about-me.md` — who you are, your work, your goals, your voice
   - `style-guide.md` — how you write (keeps Claude from sounding like AI)
   - `current-context.md` — what you're working on right now
   - `voice-samples.md` — a few examples of your real writing (optional but powerful)
3. Open `custom-instructions.md`, copy its contents, and paste them into the Project's
   **Set custom instructions** field.
4. Start working inside the Project. Fill in `about-me.md` and `current-context.md`
   using the interview prompts inside each file, or by hand.

## The one habit that makes it work

Always start your work **inside this Project** instead of a blank chat. And whenever
you make a decision or have an idea, drop it into `current-context.md` so nothing
gets lost.
